## Verification notes

- Version field: all pages use `1.0`, based on TEAM HORAY's official full-release announcement dated July 31, 2026. The Steam store metadata is referenced for feature listings, but it is not treated as the sole verification source for the current version state.
- The current public site uses conservative controller wording: gamepad input exists, but compatibility, prompts, and remapping should be verified with the specific controller and current build. The site does not claim Steam currently displays Full Controller Support.
- Steam store copy confirms: 6 weapon families with 50+ upgrades each, 60+ enemies, 10+ bosses, 6 chapters, 4-player online co-op with item exchange and teammate revival.
- Steam language table lists Simplified Chinese interface and subtitle support. Fixed language totals are not stated on the site.
- Content that had no reliable source (specific Destiny node recommendations, upgrade timing rules, phased progression routes, fixed language counts) was deleted rather than kept with disclaimers.
