# Sephiria Wiki — Builds, Guides & Tips

A decision-first Sephiria guide hub built with Next.js and static export. It is intentionally not a database wiki: pages explain player choices, trade-offs, and practical learning paths without inventing game data.

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run typecheck
npm run build
```

The production-ready static site is exported to `out/`.
